# 见稿

先弄明白听众会追问哪一句，再决定屏幕上放什么。交付时，让讲者能在 PowerPoint 里自己改关键数字、文字和关系图。

## 从手头的材料起步

| 手头有什么 | 从哪里开始 |
| --- | --- |
| 一个题目、一篇论文或零散材料 | 读材料，写逐页脚本。按用途自行选参考、出样页、校图。 |
| 已经满意的整页图或图片 PPT | 查原始文件里已有的对象，确认页序和需要独立修改的元素，直接进入按图还原。 |
| 可编辑 PPT，希望改一页或加深整稿 | 在副本里改对应页的原生对象；涉及实质内容时先回原材料。保持其他页与原稿一致。 |
| 指定学校或单位的原生母版 | 在母版副本上使用其版式、占位符与正式标识。 |

只要脚本或审美调研时，交付到所要求的环节。用户说“我自己选个方向”时，用**同一页、同一份内容**展示方向，在约定节点等反馈。用户把决定交给你，就自行看图、校正并继续。

## 先写到能讲，再生图

答辩要让台下看清证据怎么来的。读方法、图表、图注和限制，给主要论点标出原文页码。实证研究写清比较对象、时间、分母、估计量和关键假设；质性研究写清怎样选材料、怎样从原始记录形成解释。把最可能被质疑的一步留在正文。区分论文作者的发现和讲者提出的后续检验。

汇报要让听众能做一个决定。把同口径的目标与实际、差距、判断依据放到同一页。例会上容易混淆的是“多完成了几单”和“完成率提高了多少”，应把分子和分母并排。个人分享从一个具体情境开口，给朋友看当时的输入、选择或反应；使用假设时点明，第一人称经历取自讲者提供的材料。

在项目里留一份逐页脚本。每页写下**观众要弄懂什么、屏幕文字与证据、台上实际怎么说、图表从哪里来、哪几个对象以后要改**。有依据的数字此时定稿。生图前把标题和讲稿念一遍，根据听众改写；把屏幕版文字和口述版分别保存。可按三种场合对照改写实例。[脚本口述校订](references/spoken-chinese.md)

## 用一张最难画的内页定方向

答辩先选方法或结果页，汇报先选需要比较或拍板的那一页，分享先选最能带出故事的一页。看公开原作时挑一处可用的设计，如证据与图注的位置、字体层级、同尺度对照。在本次材料语境里重新设计。[六个公开参考与具体页码](references/visual-references.md)

用 GPT 内置 ImageGen 生成含标题、正文和主视觉的**完整样页**。把校过的屏幕文字、画幅、需要保留的位置和视觉重点写进提示。需要精确的图、数值或标识要保存原件，还原时用原件落位。逐字核对样页的汉字、数字、单位与图例，再检查投影能否看清。发现生图没有执行某项要求，针对这处改图。

样页定下后，保存参考图及本稿共同使用的字体层级、颜色含义、边距和图注位置。逐页调用生图，每次同时提供已定样页作为视觉参考和当页脚本，允许封面、证据页、故事页有不同构图。按稳定页码留存提示词、定稿图、数据与例外。只有准确表达内容的图才进入还原。

## 还原成真正能改的对象

从已安装的 PPT Master 自己的 SKILL.md 进入 **Generate PPTX → Image to PPTX（Quick）**，遵照对应版本的检查与导出步骤。将图像和逐页校对过的文字、原始数据、独立素材交给它，指定哪部分需要分别选取。官方流程和安装方法见下文。[PPT Master](https://github.com/hugohe3/ppt-master)

用原生文字覆盖已清字的区域，放大检查重影。表格做成单元格；需要随数值联动的图表使用可核对的源数据和内嵌工作簿。缺少原始点值的研究图可保留原件，交付时说明能整体移动。把可替换的照片和插画留作单独图片。成稿中明确哪些是原件、哪些区域由工具补绘。当前宿主缺少指定生图或还原能力时，保留已完成的脚本和素材，说明停在哪一步。

若图片稿只须改一处日期或数字，先核实目标页有没有原生对象。有就直接改，没有就只清除目标区域的旧字、修补背景、放置可编辑文字。新值要来自用户或原始记录；遇到模糊数字先找源表。把修好的这一页放回原稿的副本，其余页沿用原对象。标明此时已可编辑的具体区域。

## 需要看过程，或只改一页

已有稿可在可见的 PowerPoint 副本中定位目标页，逐步插入或修改文字、图和表。只有阶段导图可用时，提供实际画面，并标出是哪个步骤的导出。用户指定 PPT Master 官方 Default 选方向和预览时，按官方编辑器流程走。进入 Image to PPTX 的输入是已选定的图。

给重要对象起稳定的名称，在本页修改需要的对象。若某页需要独立的配图或表格数据，先复制共享资源；如果同一个数字也出现在另一页或讲稿，指出具体位置，按用户划定的范围更新。Windows 的表格试改及跨平台的结构、画面检查见[原生编辑与验收](references/edit-and-check.md)。

## 交付

新稿交付逐页脚本、ImageGen 定稿原图和可编辑 PPTX，让用户可以对照。修订交付新 PPTX 和受影响页的前后画面。核对导出后的整页，打开副本试改一个有代表性的文字、表格或图表，保存后重开。报告实际验证过什么以及仍以图片保留的部分。用户明确喜欢某一页时，记下页码、用途、喜欢的具体处理和可复用对象，作为下一次选样依据。
